# HAL 设计模式

这是用 Rust 为微控制器编写硬件抽象层 (Hardware Abstraction Layer, HAL) 的一组常见且推荐的模式. 这些模式意图作为现有 [Rust API Guidelines] 的补充, 用于为微控制器编写 HAL.

[Rust API Guidelines]: https://rust-lang.github.io/api-guidelines/
